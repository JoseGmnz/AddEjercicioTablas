1. Concepto y Tipos de Base de Datos

Articulo 1: Bases de Datos Relacionales(RDBMS)

Las bases de datos relacionales organizan la información de manera estructurada utilizando tablas. Cada tabla se compone de filas (que representan los registros individuales) y columnas (que definen los atributos de esos registros). Ejemplos muy comunes de este tipo de sistemas son MySQL y PostgreSQL.

Articulo 2: Bases de Datos No Relacionales (NoSQL)

Las bases de datos NoSQL ofrecen gran flexibilidad al permitir el almacenamiento de datos no estructurados o semiestructurados. En lugar de utilizar las tablas tradicionales, organizan la información mediante formatos como documentos, pares clave-valor o grafos. Un ejemplo muy destacado y común de este modelo es MongoDB.

2. Estructura de una Base de Datos Relacional

Componente fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos:

  • Tablas:Estructuras donde se organizan los datos.
  • Campos (Atributos):Columnas que definen la tipología de información.
  • Registros (Tuplas):Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Keys): Identificadores únicos para cada registro en una tabla.

3. Relaciones entre Tablas

Tipos de Relaciones

En un modelo relacional, las relaciones entre tablas se establecen mediante claves foráneas (foreign keys). Los tipos más comunes de relaciones son:

  • Uno a Uno (1:1): Cada registro en la primera tabla se relaciona con un único registro en la segunda tabla.
  • Uno a Muchos (1:N): Un registro en la primera tabla puede estar relacionado con múltiples registros en la segunda tabla.
  • Muchos a Muchos (N:M): Múltiples registros en la primera tabla pueden estar relacionados con múltiples registros en la segunda tabla, generalmente gestionado mediante una tabla intermedia.

Recursos de Interés

Glosario de términos

Aqui vamos a ver definiciones breves para los siguientes Términos:

  • SQL: Lenguaje de consulta estructurada utilizado para gestionar bases de datos relacionales.
  • SGDB: Sistema de Gestión de Bases de Datos.
  • Normalización: Proceso de organizar los datos en una base de datos para reducir la redundancia y mejorar la integridad.
  • Clave Foránea: Campo que vincula dos tablas en una relación.
